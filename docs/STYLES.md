# Styles of colour mode

This file lists the style presets of `colour` mode and the paths that
`render.style_overrides` accepts.

## Presets

`render.style` names one preset. Each preset is a style file of Azgaar's
Fantasy Map Generator (FMG), kept without changes in
`crates/inkland-render/assets/fmg/styles`. A value that a preset does not
give comes from the `default` preset.

| Name | FMG file |
|---|---|
| `default` | `src/model/styles/default-styles.json` |
| `ancient` | `public/styles/ancient.json` |
| `atlas` | `public/styles/atlas.json` |
| `cinderwood` | `public/styles/cinderwood.json` |
| `clean` | `public/styles/clean.json` |
| `cyberpunk` | `public/styles/cyberpunk.json` |
| `dark-seas` | `public/styles/darkSeas.json` |
| `frostbite` | `public/styles/frostbite.json` |
| `gloom` | `public/styles/gloom.json` |
| `ink` | `public/styles/ink.json` |
| `light` | `public/styles/light.json` |
| `monochrome` | `public/styles/monochrome.json` |
| `night` | `public/styles/night.json` |
| `pale` | `public/styles/pale.json` |
| `watercolor` | `public/styles/watercolor.json` |

## Overrides

Each key of `render.style_overrides` is the path of one value, for
example:

```json
"style_overrides": {
  "ocean.groups.base.attrs.fill": "#a9d5ef",
  "relief.options.set": "gray",
  "labels.groups.state.attrs.fill": "#202020"
}
```

- A path starts with a style element, then `groups.<name>` zero or more
  times, then `attrs` or `options`, then the key.
- An `attrs` value is an SVG attribute of the group of the layer. `null`
  removes the attribute.
- An `options` value is a value that the renderer reads.
- A value is a string, a number, a boolean, or `null`.

Sizes and line widths are in map pixels of FMG. inkland puts the world in
a map of 1920 x 1080 pixels and scales the pixels to the page. The label
font sizes come from `render.font_sizes_pt`, not from the style.
